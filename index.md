# Home Use AI Connector

Home Use AI Connector is a personal software project that connects an AI assistant to the developer's Pinterest account.

The application is intended for personal use. It allows an authenticated user to retrieve and analyze their own Pinterest boards and Pins in order to help organize saved content, search collections, and provide personalized recommendations.

## Pinterest Data

Access to Pinterest data occurs only after the user explicitly authorizes the application through Pinterest's OAuth system.

The initial version of the application is intended to use read-only access to the authenticated user's Pins and boards.
